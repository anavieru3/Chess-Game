## **Running the game**

Open the project in IntelliJ and run the 'Main class'. You'll need to create an account on first run.

## **Features**

- **Login & accounts** - Create account and authenticate
- **Play vs Computer** - AI makes random moves
- **Save and resume games** - Leave anytime and come back later
- **All chess rules** - Every piece moves correctly (king, queen, rook, bishop, knight, pawn)
- **Point system** - Earn points for captured pieces and victories
- **Move validation** - Won't let you make illegal moves

 ## How to Play

1. Login or create new account
2. Choose "New Game" and select your color
3. The board displays like this:
   - Select a piece position (e.g., `B2`) to see where it can move
   - Move using the highlighted squares `B2-B3`
4. Win by checkmate or opponent resignation
